# 1. Who starts it

Every skill has a trigger. Either **you type it**, or **the model may reach for it**.

You-typed skills are rituals. Grill. Spec. Implement. Setup. If the model can see their descriptions, it will try to run the ritual without you. That costs tokens and it costs control.

Matt hides those descriptions (`disable-model-invocation`). The name shows to you. The model does not shop the menu.

Model-reached skills are discipline: tdd, review, diagnose. Small. One job. Safe to leave visible.

**Rule:** a you-typed skill may call a model skill. It may not call another you-typed skill. Setup is run-once, by you, never by a sibling.

**Try:** pick one ritual in your shop. Make it a click. If it fires on submit, it is wrong.
