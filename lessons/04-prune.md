# 4. Prune

Skill hell is not a shortage of skills. It is too many, overlapping, and stale.

- **One source.** If two files say when Type is set, delete one.
- **Sediment.** Shared docs collect leftover advice. Cut it.
- **No-ops.** If deleting a sentence does not change the agent, it was decoration.

Matt’s own repo dropped unused skills. That is the point.

**Try:** delete one skill this week. If nothing breaks, it was sediment.
