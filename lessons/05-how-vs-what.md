# 5. Skills are how. MCP is what.

A **skill** is permission and procedure. How the agent is allowed to work.

**MCP** is a plug. What the agent can touch: a sheet, a repo, a box, a token.

Matt teaches both. They are not substitutes.

- Install his skills as files or as a Claude plugin.
- Build an MCP server when you need a tool.
- Do not run Skills Over MCP. It turns every `SKILL.md` into a model-visible tool and undoes his hide-the-description flag.

**Try:** list your MCP servers. If one of them is “all of Matt’s skills,” remove it.
