# 6. The loop

```
grill → spec → tickets → implement → architecture → grill
```

1. **Grill** — you type it. Shared language before code.
2. **Spec** — the conversation becomes a document. Not a chat dump.
3. **Tickets** — vertical slices with blocking edges.
4. **Implement** — you start it. The model may reach for tdd and review.
5. **Architecture** — clean what piled up. Feed it back or the pipe rots.

Without the last edge it is a pipeline, not a loop.

In Methodology this is Berd (grill + spec) → you confirm Type → Buzz (implement) → fleet. The form never starts the ritual.
