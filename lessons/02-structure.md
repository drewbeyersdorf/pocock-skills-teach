# 2. Keep the file small

A skill has two kinds of text.

**Steps** — the procedure. Find context. Confirm the seam. Write the spec.
**References** — templates, definitions, examples.

Put steps in the skill. Point at references. Do not paste the ADR template into `SKILL.md`.

A fat skill is a tax. It is also a lie waiting to happen: two copies of the template, one stale.

**Try:** open a skill you wrote. If a branch-only template is inline, move it to a file and leave a pointer.
