# Teach Pocock’s agent-skill rubric

This repo is a **teaching companion**. It is not a fork of [mattpocock/skills](https://github.com/mattpocock/skills). It does not copy his `SKILL.md` files. It does not wrap them as MCP tools.

Read him first:

- Talk — [Building Great Agent Skills](https://youtu.be/UNzCG3lw6O0)
- Files — [github.com/mattpocock/skills](https://github.com/mattpocock/skills)
- MCP (tools, not skills) — [AI Hero tutorial](https://www.aihero.dev/model-context-protocol-tutorial)

Then walk these notes in order:

1. [Who starts it](lessons/01-trigger.md)
2. [Keep the file small](lessons/02-structure.md)
3. [Words that steer](lessons/03-steering.md)
4. [Prune](lessons/04-prune.md)
5. [Skills are how. MCP is what.](lessons/05-how-vs-what.md)
6. [The loop](lessons/06-the-loop.md)

The picture is in [GRAPH.md](GRAPH.md).

**Rule this repo exists to teach:** a skill is how the agent is allowed to work. MCP is a plug for a tool. Do not turn thirty-five skills into model-visible tools.
